  1. Choice of p
# IDW prediction at a single point (x0, y0)
idw_point <- function(x0, y0, x, y, z, p) {
  d <- sqrt((x - x0)^2 + (y - y0)^2)
  if (any(d == 0)) return(mean(z[d == 0]))
  w <- 1 / d^p
  sum(w * z) / sum(w)
}
 
x <- dati$XUTM; y <- dati$YUTM; z <- dati$totanno
n <- nrow(dati)
 
# Station-to-station distance matrix (computed once)
D <- as.matrix(dist(cbind(x, y)))
diag(D) <- Inf   # leave-one-out: a station never predicts itself
 
# Leave-one-out predictions for a given p
idw_loocv <- function(p) {
  W <- D^(-p)                 # diag becomes 0 since Inf^(-p) = 0
  as.numeric(W %*% z / rowSums(W))
}
 
p_grid <- seq(0.1, 6, by = 0.1)
cv <- t(sapply(p_grid, function(p) {
  e <- z - idw_loocv(p)
  c(p = p, RMSE = sqrt(mean(e^2)), MAE = mean(abs(e)))
}))

  • Association: Pearson tests the linear relationship, Spearman the monotone one. A small p-value (below 0.05) rejects “no association”; the sign gives the direction. If Pearson and Spearman differ a lot, the relationship is non-linear or driven by outliers.
  • Strength: \(R^2\) in summary(fit_lm) is the share of rainfall variance explained by elevation alone (and equals the Pearson correlation squared). The slope is in mm of rain per metre of elevation; use confint to see whether 0 is excluded.

  1. Choice of p in IDW by leave-one-out cross-validation

The IDW estimator at point \(s_0\) is

\[\hat z(s_0)=\frac{\sum_i d(s_0,s_i)^{-p} z(s_i)}{\sum_i d(s_0,s_i)^{-p}}.\]

For each station \(i\) I remove it, predict it from the other \(n-1\), and compute \(\mathrm{MSE}(p)=\frac1n\sum_i(z_i-\hat z_{-i})^2\).

X <- cbind(dati$XUTM, dati$YUTM)
z <- dati$totanno
D <- as.matrix(dist(X))
diag(D) <- Inf                       # leave-one-out: a station never predicts itself

cv_mse <- function(p) {
  W <- 1 / D^p                       # Inf^p = Inf -> weight 0 on the diagonal
  pred <- as.vector(W %*% z) / rowSums(W)
  mean((z - pred)^2)
}

p_grid <- seq(0.25, 8, by = 0.25)
cv <- data.frame(p = p_grid, MSE = sapply(p_grid, cv_mse))

# refine around the minimum of the coarse grid
p0 <- cv$p[which.min(cv$MSE)]
opt <- optimize(cv_mse, interval = c(max(0.01, p0 - 0.25), p0 + 0.25))
p_opt <- opt$minimum
cat("Optimal p:", round(p_opt, 3), "| CV MSE:", round(opt$objective, 1),

How to assess:

  • Is the optimum a real minimum? The red line should sit in the interior of the MSE curve, with MSE rising on both sides. If the minimum falls at the edge of the tested range (0.25 or 8), extend p_grid.
  • Is it well determined? A very flat curve around the minimum means that nearby values of p are practically equivalent, so the choice is not critical.
  • Does IDW beat a trivial predictor? The relative skill should be clearly positive (1 = perfect, 0 = no better than the mean). Points close to the red 1:1 line confirm good predictions; systematic departures at high or low values (IDW smooths extremes) show its bias.
  • Caveat: the minimum CV MSE is slightly optimistic because the same data both choose p and evaluate it. For a stricter check, repeat with k-fold CV or hold out some stations.

idw_predict <- function(x0, y0, x, y, z, p) {
  d <- sqrt(outer(x0, x, "-")^2 + outer(y0, y, "-")^2)
  d[d < 1e-6] <- 1e-6                # a grid point on a station returns (almost exactly) that station's value
  W <- 1 / d^p
  as.vector(W %*% z) / rowSums(W)
}

How to assess:

  • Basic consistency: no NA, and the predicted range must fall inside the observed range (IDW with positive weights can never exceed it; if it does, there is a bug). Because of this, IDW cannot predict peaks above the highest station, nor the valleys below the lowest, and the map looks smoother than reality.
  • Match with the data: where the circles (observations) and the small points (predictions) have the same colour, the map reproduces the data. Visible “bull’s-eyes” around isolated stations are typical of IDW with large p.
  • Reliability: grid points whose distance to the nearest station is much larger than the typical station spacing (last two outputs) are extrapolations; read the map there with caution.
  • No uncertainty measure: IDW does not give prediction variances. If you need them, kriging with the semivariogram fitted in Section 1.4 is the natural next step.
